# 🌐 Primeiro Portfólio

> Meu primeiro portfólio pessoal, criado para apresentar informações, habilidades e projetos no início da minha jornada como desenvolvedor.

---

## 📌 Sobre o Projeto

Este foi um dos primeiros projetos desenvolvidos para estruturar uma apresentação profissional na web. A página reúne informações pessoais, trajetória, valores, galeria de projetos e redes de contato em uma navegação visual simples e intuitiva.

O projeto foi fundamental para consolidar os fundamentos de **HTML semântico**, estilização com **CSS**, organização de layout responsivo e interações básicas com **JavaScript**, além de servir como base para a evolução do meu portfólio atual.

---

## ✨ Seções do Site

- **Home:** Apresentação inicial com chamada para ação e foto de perfil.
- **Sobre:** Resumo pessoal detalhando minha trajetória, localização (Manaus - AM) e valores como Humildade e Evolução.
- **Projetos:** Galeria para exibição e destaque dos projetos desenvolvidos.
- **Contato:** Links diretos para redes sociais (Instagram, LinkedIn, GitHub e WhatsApp).

---

## 🛠️ Tecnologias Utilizadas

Para a construção deste portfólio, utilizei:

- **HTML5:** Estruturação semântica das seções, navegação e conteúdo.
- **CSS3:** Estilização visual, esquema de cores dark, fontes, posicionamento e layout responsivo.
- **JavaScript:** Interações e dinâmicas da página.

---
